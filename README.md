# Ecos Desenvolvimento

Site institucional one-page desenvolvido em Angular 19.

```bash
npm install
npm start
```

Build de produção: `npm run build`.

## Padrão visual

- A documentação de design e manutenção está na [wiki](docs/wiki/README.md).
- Alterações de interface devem seguir o skill `.agents/skills/ecos-design-system`.
