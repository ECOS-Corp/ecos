# Identidade visual

## Conceito

A identidade da Ecos é guiada pelo conceito **tecnologia com ressonância humana**. Círculos, ondas e sinais representam ideias que se propagam e geram impacto. A composição combina precisão tecnológica com linguagem editorial e bastante respiro.

## Paleta

| Papel | Cor |
| --- | --- |
| Azul principal | `#1167e8` |
| Azul escuro | `#0755ca` |
| Azul-marinho | `#07162d` |
| Fundo escuro | `#08162d` / `#0b1b35` |
| Papel | `#f7f9fc` |
| Texto secundário | `#53647b` |

O azul identifica ações, frases de destaque e a assinatura da marca. Fundos escuros criam momentos imersivos; fundos claros criam leitura editorial. Não adicionar novas cores de destaque sem uma função semântica clara.

## Tipografia

- **Manrope:** títulos, números e marca.
- **DM Sans:** textos, navegação e controles.

Títulos usam espaçamento entre letras negativo e altura de linha compacta. Textos corridos usam altura de linha generosa. A combinação deve transmitir firmeza sem prejudicar a leitura.

## Marca

A aplicação contém uma marca vetorial temporária baseada em ondas concêntricas. Ela deve ser substituída pelo arquivo oficial quando disponibilizado, preservando proporção, área de proteção e contraste. Nunca distorcer, aplicar sombra ou alterar as cores internas de uma marca oficial.
