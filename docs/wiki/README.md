# Wiki — Ecos Desenvolvimento

Esta wiki registra as decisões que mantêm o site institucional visualmente consistente e fácil de evoluir.

## Conteúdo

- [Identidade visual](identidade-visual.md): cores, tipografia, marca e direção estética.
- [Componentes e padrões](componentes-e-padroes.md): padrões reutilizáveis da interface.
- [Conteúdo e acessibilidade](conteudo-e-acessibilidade.md): tom de voz e requisitos inclusivos.
- [Manutenção](manutencao.md): fluxo seguro para alterações futuras.

## Fonte de verdade

Os tokens efetivamente usados pela aplicação estão em `src/styles.scss`. Os estilos dos componentes estão em `src/app/app.component.scss`. Esta wiki explica a intenção desses valores e deve ser atualizada quando uma decisão visual mudar.

Para assistentes de código, o skill `.agents/skills/ecos-design-system/SKILL.md` é obrigatório em tarefas relacionadas à interface da Ecos.
